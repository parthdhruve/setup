## Prohibitions
- NEVER `git push`

## Commit Guidance
- You MUST create one commit for each "atomic chnages"
  - Commits MUST be small (< 150 lines)
  - Commits MUST have a concise description of included changes
  - Commits MUST NOT contain information on if/which agent authored the commit
  - Commits MUST leave the project in a good state (i.e., buildable, tests passing, etc., as applicable)
